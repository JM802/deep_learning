一、线性模型与优化

  1. 写出小批量线性回归的前向计算、平方损失和 SGD 参数更新。说明为什么如果损失已经用了 mean()，优化器里通常不应再除以 batch size。
    参考答案

    y_hat = Xw + b，损失可写为 L = mean(1/2 * (y_hat - y)^2)，更新 w = w - lr * grad(w)，b = b - lr * grad(b)。如果反向传播来自平均损失，梯度已经是 batch 平均梯度，再除一次会让有效学习率缩小 batch_size 倍。

  2. 设 X 形状为 (64, 10)，w 为 (10, 1)，b 是标量。预测结果形状是什么？如果标签 y 是 (64,)，直接相减可能出现什么问题？
    参考答案

    Xw 是 (64, 1)。若 y 是 (64,)，与 (64,1) 相减可能广播成 (64,64)，导致错误损失。应把 y reshape 成 (64,1)。

  3. 为什么小批量训练通常先打乱样本？如果数据按类别排序而不打乱，会怎样影响 softmax 分类训练？
    参考答案

    打乱能让每个 mini-batch 更接近总体分布，使梯度估计更稳定。若样本按类别排序，连续 batch 可能只含一个类别，梯度方向偏置严重，训练震荡或收敛慢。

  4. Softmax 回归为什么仍是线性模型？它和线性回归的输出、损失分别有什么不同？
    参考答案

    它的 logits 仍是输入特征的线性函数 O = XW + b。线性回归输出连续值，用平方损失；softmax 回归输出类别概率分布，用交叉熵损失。

  5. 对 logits [2, 1, 0]，真实类别是第 1 类。无需算精确小数，写出交叉熵损失形式，并说明提高真实类别 logit 会如何影响损失。
    参考答案

    损失为 -log(exp(2)/(exp(2)+exp(1)+exp(0)))。提高真实类别 logit 会提高对应 softmax 概率，因此降低负对数似然损失。

  6. 为什么实际实现 softmax 时常用“减去最大 logit”的技巧？这会改变概率结果吗？
    参考答案

    为了避免 exp 溢出。对所有 logits 同时减去同一个常数不会改变 softmax 概率，因为分子分母都会乘同一个因子。

二、MLP、激活函数与泛化

  1. 证明直觉：如果一个网络只有多层线性层、没有激活函数，它为什么仍等价于一层线性模型？
    参考答案

    线性变换的复合仍是线性变换。例如 XW1W2 + b1W2 + b2 可改写成 XW' + b'。因此没有非线性激活时，堆很多层并不能表达非线性边界。

  2. 比较 ReLU、sigmoid、tanh 的梯度特性。为什么现代 MLP/CNN 常默认使用 ReLU 或其变体？
    参考答案

    sigmoid 和 tanh 在输入绝对值大时容易饱和，梯度接近 0；ReLU 在正半轴梯度为 1，优化更直接，计算也简单。但 ReLU 负半轴梯度为 0，可能出现死亡 ReLU。

  3. 一个 MLP 输入维度 784，隐藏层 256，输出 10。计算两层全连接的参数量，包含 bias。
    参考答案

    第一层：784*256 + 256 = 200960。第二层：256*10 + 10 = 2570。总计 203530。

  4. 训练误差很低、验证误差很高，最可能是什么问题？给出三种应对策略，并说明各自降低了什么风险。
    参考答案

    最可能是过拟合。策略：权重衰减限制权重幅度；dropout 减少隐藏单元共适应；数据增强或增加数据提升训练分布覆盖；早停也可防止继续记忆训练集。

  5. 权重衰减和 dropout 都是正则化，但它们的机制有什么本质差异？
    参考答案

    权重衰减直接在目标函数中惩罚大权重，使参数更小更平滑。Dropout 在训练时随机屏蔽部分激活，迫使网络不要依赖少数特征组合，近似集成多个子网络。

  6. 为什么训练时使用 dropout，推理时通常关闭 dropout？若推理时仍随机 dropout，会发生什么？
    参考答案

    推理阶段需要确定、稳定的预测，训练时的缩放已经让激活期望匹配。推理时继续随机 dropout 会让同一输入输出不稳定，通常降低精度。

  7. 梯度消失和梯度爆炸分别会让训练曲线呈现什么症状？请至少写出两个排查方向。
    参考答案

    梯度消失：前面层学习极慢，loss 降不动。梯度爆炸：loss 变成 NaN 或剧烈震荡。排查：初始化、学习率、激活函数、归一化、残差连接、梯度裁剪。

三、深度学习计算与 PyTorch 逻辑

  1. 在 PyTorch 中，为什么参数更新通常放在 torch.no_grad() 中？更新后为什么要清空梯度？
    参考答案

    参数更新不是模型前向计算的一部分，不应被 autograd 记录。梯度默认累积，不清空会把多个 batch 的梯度加在一起，除非你有意做梯度累积。

  2. 解释 nn.Module、层、块之间的关系。为什么现代网络更常用块来组织代码？
    参考答案

    nn.Module 是可包含参数和子模块的基类。层是小模块，块是多个层或子块的组合。块能复用结构、清晰管理参数，并让复杂网络像搭积木一样构建。

  3. 保存模型时，为什么通常保存 state_dict 而不是整个模型对象？
    参考答案

    state_dict 只保存参数和缓冲区，和代码结构解耦，更轻量、更稳定。加载时由当前代码定义结构，再填入权重。

  4. 若模型在 GPU 上、输入数据在 CPU 上，会发生什么？正确做法是什么？
    参考答案

    通常会报 device mismatch 错误。应将模型和所有参与计算的张量移动到同一设备，如 model.to(device) 和 X.to(device)、y.to(device)。

  5. 自定义层至少需要实现什么？如果该层有可学习参数，应该如何注册？
    参考答案

    至少实现 forward。可学习参数应使用 nn.Parameter 或子模块层保存为模块属性，这样优化器才能发现它们。

四、CNN 基础：卷积、通道、池化、LeNet

  1. 为什么 CNN 比把图像展平成向量后接 MLP 更适合图像？请从局部性、平移等变性、参数共享三个角度回答。
    参考答案

    图像局部邻域有强相关性，卷积核只看局部窗口；同一卷积核在不同位置共享参数，能检测相同模式；池化和局部响应使模型对小幅平移更稳健。展平 MLP 会破坏空间结构且参数巨大。

  2. 输入图像 (N=32, C=3, H=64, W=64)，卷积层 out_channels=16，核 5x5，padding=2，stride=1。输出形状和参数量是多少？
    参考答案

    空间尺寸不变：(64 + 2*2 - 5)/1 + 1 = 64。输出 (32,16,64,64)。参数量 16*3*5*5 + 16 = 1216。

  3. 输入 28x28，卷积核 3x3，padding=0，stride=2。输出空间尺寸是多少？若想保持 28x28，stride 和 padding 如何选择？
    参考答案

    输出 floor((28 - 3)/2) + 1 = 13。若核为 3，要保持尺寸，通常 stride=1，padding=1。

  4. 多输入通道卷积中，每个输出通道是怎样生成的？为什么参数量会乘以 C_in？
    参考答案

    每个输出通道都有一组覆盖所有输入通道的卷积核，对每个输入通道卷积后求和，再加 bias。因此一个输出通道需要 C_in*K_h*K_w 个权重。

  5. 1x1 卷积看起来没有空间窗口，它有什么用？至少说出两个用途。
    参考答案

    1x1 卷积在每个像素位置混合通道。用途：改变通道数、降维减少计算、升维增强表达、在通道维度引入带激活的非线性组合。

  6. 最大池化和平均池化分别偏向保留什么信息？它们是否改变通道数？
    参考答案

    最大池化偏向保留最显著局部响应，平均池化偏向保留局部整体趋势。常规池化只在每个通道内做空间聚合，不改变通道数。

  7. LeNet 的基本结构是什么？它体现了 CNN 的哪条经典设计路线？
    参考答案

    典型结构是卷积、激活、池化重复若干次，再接全连接分类器。设计路线是逐步降低空间分辨率、逐步增加或保留语义特征，最后分类。

五、现代 CNN 架构比较

  1. AlexNet 相比 LeNet 的关键进步是什么？请从数据规模、网络容量、激活函数、正则化四个角度回答。
    参考答案

    AlexNet 面向更大规模图像任务，网络更深更宽；大量使用 ReLU 改善训练；使用 dropout 等手段缓解过拟合；整体证明深层 CNN 在大规模视觉识别中的威力。

  2. VGG 为什么偏爱堆叠多个 3x3 卷积，而不是直接用一个大卷积核？以两个 3x3 与一个 5x5 为例说明。
    参考答案

    两个 3x3 的感受野可覆盖 5x5，但引入两次非线性，表达能力更强。参数上，在同通道数 C 时，两个 3x3 约 18C^2，一个 5x5 是 25C^2，更省参数。

  3. NiN 的核心思想是什么？全局平均池化相比最后的大型全连接层有什么优势？
    参考答案

    NiN 用 1x1 卷积等结构在每个空间位置上做更复杂的通道混合，并用全局平均池化输出类别分数。GAP 无可学习参数，减少过拟合，并让通道与类别更直接对应。

  4. GoogLeNet 的 Inception 块为什么使用多个分支？为什么常在大卷积前放 1x1 卷积？
    参考答案

    多个分支用不同核大小和池化提取多尺度特征，再沿通道拼接。大卷积前的 1x1 卷积用于压缩通道，显著减少计算和参数，同时增加非线性。

  5. BatchNorm 在全连接层和 CNN 中分别通常沿哪些维度统计均值和方差？
    参考答案

    全连接层通常对 batch 维度统计每个特征的均值方差。CNN 中通常对每个通道独立统计，统计范围包括 N,H,W，即每个通道共享一组均值方差、gamma、beta。

  6. BatchNorm 的训练阶段和推理阶段有什么区别？
    参考答案

    训练时使用当前 mini-batch 的均值方差，并更新运行均值方差。推理时使用训练过程中积累的运行统计量，保证预测稳定且不依赖当前 batch。

  7. ResNet 的残差块公式是什么？为什么它能缓解“网络加深后训练误差反而变差”的退化问题？
    参考答案

    公式是 H(x)=F(x)+x。如果新增层没有帮助，残差分支可以学成接近 0，让块近似恒等映射；这样深层网络至少更容易不比浅层差，也改善梯度传播。

  8. ResNet 中什么时候需要用投影捷径，例如 1x1 卷积？为什么？
    参考答案

    当输入和残差输出的形状不同，例如通道数变化或空间尺寸因 stride 改变时，需要投影捷径把 x 变成可相加的形状。

六、综合诊断题

  1. 你训练 Fashion-MNIST，训练准确率 99%，测试准确率 84%。模型是三层 MLP。请给出最可能原因、验证方法、三步修改方案。
    参考答案

    最可能过拟合。验证方法：画训练/验证损失曲线，看验证损失是否先降后升；比较模型容量和数据增强情况。方案：加入 weight decay/dropout；减小隐藏层或早停；把 MLP 换成 CNN 以利用图像结构。

  2. 一个 CNN 报错：全连接层期望输入 4096 维，但实际 flatten 后是 3136。你如何系统排查？
    参考答案

    逐层打印或用 dummy input 跑 shape；检查卷积核、padding、stride、pooling 是否和手算一致；不要硬猜 flatten 维度，可在初始化时用一次前向推断，或使用自适应池化固定输出形状。

  3. 同样参数量预算下，为什么一个小 CNN 往往比一个大 MLP 更适合图片分类？
    参考答案

    CNN 的参数共享让参数用在可复用局部模式上；局部连接保留空间邻域归纳偏置；通道层级能从边缘到纹理再到部件组合。MLP 对每个位置单独学习连接，数据效率低。

  4. 训练 loss 变成 NaN。请按优先级列出五个可能原因和对应处理。
    参考答案

    学习率过大：降低学习率；梯度爆炸：梯度裁剪或归一化；softmax/log 手写数值不稳定：用框架交叉熵；数据有 NaN/Inf：检查输入和标签；初始化不当：改用合适初始化或 BatchNorm。

  5. 如果你要从零实现一个小型图像分类器，写出从数据到评估的最小训练流程。
    参考答案

    准备 Dataset/DataLoader；定义模型；选择损失如交叉熵；选择优化器；训练循环包括 forward、loss、zero_grad、backward、step；定期在验证集 eval 模式评估；保存最佳 state_dict。

  6. 请把线性回归、softmax 回归、MLP、LeNet、ResNet 串成一条“表达能力提升路线”，每一步说明新增了什么归纳偏置或优化技巧。
    参考答案

    线性回归学习连续线性关系；softmax 回归把线性模型用于多分类概率；MLP 加非线性提高表达能力；LeNet 引入卷积的局部性和参数共享；ResNet 用残差连接让更深 CNN 可训练。

七、挑战题：真正检验理解

  1. 设计一个输入 3x32x32、输出 10 类的小 CNN。要求写出每层输出形状，并解释为什么最后不直接使用超大的全连接层。
    参考答案

    示例：Conv 3->32, 3x3,pad1 输出 32x32x32；MaxPool2 输出 32x16x16；Conv 32->64 输出 64x16x16；MaxPool2 输出 64x8x8；GAP 输出 64；Linear 64->10。避免大 FC 是为了减少参数、降低过拟合，并保留 CNN 的空间归纳偏置。

  2. 解释“更深的网络不一定更容易过拟合，可能反而更难优化”。这个说法和 ResNet 的动机有什么关系？
    参考答案

    过拟合表现为训练误差低、验证误差高；退化问题是更深网络训练误差也变高，说明优化失败。ResNet 通过残差学习和恒等捷径，让新增层更容易至少学成不破坏原函数的映射。

  3. 给定一个错误观点：“BatchNorm 只是正则化，所以有 Dropout 就不需要 BatchNorm。”请反驳。
    参考答案

    BatchNorm 的主要作用包括稳定中间激活分布、改善梯度传播、允许更大学习率，也可能带来正则化效果。Dropout 主要通过随机屏蔽激活减少共适应。两者机制不同，不能简单互相替代。

  4. 给定一个错误观点：“1x1 卷积没有看邻居，所以没用。”请反驳。
    参考答案

    1x1 卷积虽然不聚合空间邻居，但能在每个位置混合所有通道。它可做通道降维/升维、降低大卷积计算量，并配合激活函数增加通道维度的非线性表达。
