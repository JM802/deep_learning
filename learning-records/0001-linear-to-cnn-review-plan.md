# 0001 - Linear To CNN Review Plan

## Date

2026-07-07

## Context

The learner has completed or is reviewing chapters 1-7 of a deep learning course. Local notes include linear networks, MLPs, regularization, deep learning computation, CNN basics, and modern CNNs.

## Learning Insight

The most valuable review format is interleaved retrieval: mix definitions, shape calculations, parameter counts, code reasoning, and architecture comparisons. This prevents the learner from only recognizing familiar notes and instead forces active reconstruction.

## Decision

Create a compact HTML lesson with a structured question bank and hidden answers, plus a separate quick reference sheet.

## Next Review

After attempting the questions, identify weak areas and generate a second set focused only on mistakes.
