核心公式

主题你必须能从记忆中写出
线性回归y_hat = Xw + b，平方损失 1/2 * (y_hat - y)^2，小批量 SGD 沿负梯度更新。
Softmax 回归softmax(o)_i = exp(o_i) / sum_j exp(o_j)，交叉熵 -log p_y。
MLP仿射变换加非线性激活：H = phi(XW + b)。没有激活函数，多层线性层仍等价于一层线性层。
权重衰减在损失中加入 lambda/2 * ||w||^2，限制权重过大，降低过拟合风险。
Dropout训练时随机置零一部分隐藏单元，并按保留概率缩放；推理时不用随机丢弃。
卷积输出高度：floor((H + 2P - K) / S) + 1。宽度同理。
卷积参数量C_out * C_in * K_h * K_w + C_out，若有 bias。
BatchNorm标准化后再学习缩放和平移：gamma * x_norm + beta。
ResNetH(x) = F(x) + x，让网络学习残差 F(x)。

形状规则

线性层

输入 (batch, d)，权重 (d, h)，输出 (batch, h)。

图像张量

PyTorch 常用 (N, C, H, W)。卷积改变 C, H, W，通常不改变 N。

1x1 卷积

在每个空间位置上混合通道，可改变通道数，常用于降维、升维和增加非线性。

池化

通常只改变空间尺寸，不改变通道数。最大池化偏局部显著特征，平均池化偏整体平滑。

架构对比

模型关键思想复习时要会回答
LeNet卷积 + 池化 + 全连接的早期 CNN。为什么比把图像展平后接 MLP 更适合图像？
AlexNet更深更宽，ReLU，Dropout，大规模视觉任务。它相对 LeNet 的工程和表达能力提升是什么？
VGG用多个 3x3 卷积块堆叠。为什么多个小卷积核可替代大卷积核？
NiN1x1 卷积替代部分全连接思想，全局平均池化。GAP 如何减少参数和过拟合？
GoogLeNetInception 多分支提取多尺度特征。为什么需要 1x1 卷积做通道压缩？
BatchNorm稳定中间层分布，改善优化。训练和推理的统计量有什么不同？
ResNet残差连接让深层网络更易优化。为什么退化问题不只是过拟合？
